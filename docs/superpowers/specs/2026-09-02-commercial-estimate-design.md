# 상가 견적서 설계 명세

작성일: 2026-09-02  
상태: 대표 승인 완료

## 1. 목표와 범위

다함 ERP에 주거용과 데이터가 완전히 분리된 상가 전용 견적서를 새로 만든다. 견적 작성자는 공종별 수량을 입력하고 자동 산출된 인건비와 자재비를 확인·수정하며, 일반관리비·이윤·부가세를 적용해 고객용 견적서를 저장하고 출력한다.

- 가구·집기와 간판 공종은 제외한다.
- 모든 수량·단가·자동 산출 결과는 해당 견적에서 직접 수정할 수 있다.
- 기본단가 변경은 설정에 저장하며 기존 견적은 소급 변경하지 않는다.
- 인건비, 자재비, 현장경비를 내부 화면에서 분리한다.
- 고객용 출력물에는 원가와 이윤을 숨기고 공종별 판매금액만 표시할 수 있다.
- 주거용과 동일한 일반관리비·이윤·부가세 계산 방식을 사용한다.

## 2. 화면과 작성 흐름

`상가 견적 새로 만들기 → 현장정보·평수 입력 → 공종 선택 → 수량 입력 → 자동 계산 → 단가 조정 → 일반관리비·이윤·부가세 적용 → 저장·미리보기·출력`

- 중앙: 16개 공종의 접이식 목록. 선택한 공종만 펼쳐 세부 항목을 입력한다.
- 우측: 인건비, 자재비, 현장경비, 일반관리비, 이윤, 부가세, 최종 견적금액을 실시간 표시한다.
- 공종 및 항목에는 `자동 계산`, `직접 수정 가능` 상태를 표시한다.
- 선택하지 않은 공종은 고객용 견적서에서 숨긴다.
- 작업 중 자동 저장, 임시저장, 미리보기, 최종 저장을 제공한다.
- 이윤은 견적마다 퍼센트 또는 고정금액으로 수정할 수 있고, 기본 이윤율은 설정에서 관리한다.

## 3. 공통 계산 규칙

- 면적 단위: 평과 ㎡를 모두 지원하고 `1평 = 3.3058㎡`로 환산한다.
- 일반 자재 로스율: 별도 표기가 없으면 15%.
- 발주 단위가 장·박스·단이면 전체 현장 물량에 로스를 적용한 뒤 마지막에 한 번 올림한다.
- 자동 수량과 금액은 원 계산값을 보존하면서 사용자 수정값을 우선 적용한다.
- 최소 인건비는 동일 공종 내 인건비 합계가 기준 미만일 때 차액만 보정한다.
- 야간·휴일 할증이 명시된 공종은 인건비에 30%를 가산한다.
- 목수 1품은 350,000원이다. `1품 추가`는 인건비 350,000원과 추가 자재비 245,000원(추가 인건비의 70%)을 더하며, 이 70% 규칙은 수동 품 추가에만 적용한다.
- 자동 계산 내역에는 산식과 예상 발주 수량을 펼쳐볼 수 있게 한다.

## 5. 공종별 기본값

### 5.1 가설·보양

- 가벽: 목상 30×30×2400 소송 다루끼, 12개/단, 32,000원/단. 간격 450mm. 일반합판 5T 1220×2440, 16,000원/장. 단면 기본, 양면 선택. 부자재 10%, 로스 15%. 생산성 단면 10㎡/품, 양면 7㎡/품.
- 바닥 보양(평당): 보양지 인건비 7,000 + 자재 5,000; 플로베니아 인건비 8,000 + 자재 6,000; 보양지+플로베니아 인건비 13,000 + 자재 12,000.
- 문·창 보양(개소): 비닐 인건비 15,000 + 자재 10,000; 비닐+플로베니아 인건비 25,000 + 자재 20,000.
- 엘리베이터: 내부 기본 280,000(인건비 120,000, 자재 160,000), 내부+입구·프레임 전체 400,000(인건비 180,000, 자재 220,000).
- 공용 동선 보양: 150,000/식(인건비 60,000, 자재 90,000), 수량 조정 가능.
- 먹매김과 현장정리는 이 공종에서 제외한다.

### 5.2 철거·폐기물

- 폐기물 반출·운반·처리: 450,000원/식 단일 항목.
- 철거 내역을 가중 합산해 식 수를 자동 추천하고 사용자가 수정한다. 추천 환산 기준: 비닐·카펫 30평/식, 데코타일 20평/식, 바닥·목재 15평/식, 타일만 10평/식, 타일+몰탈 7평/식, 석고·합판벽 실제면적 10평/식, 천장 15평/식, 화장실 2칸/식.
- 바닥 철거 인건비/평: 비닐·카펫 5,000; 데코타일 15,000; 강화마루 20,000; 강마루 30,000; 타일만 50,000; 타일+몰탈 80,000; 에폭시 연삭·철거 30,000.
- 벽 철거 인건비/평(실제면적): 도배·필름 8,000; 석고벽 25,000; 목상+합판 35,000; 경량+석고 40,000; 조적벽 70,000; 벽타일 80,000.
- 천장 철거 인건비/평: 비석면 텍스 15,000; 석고 25,000; 목상+합판 35,000; 경량+석고 35,000; 디자인천장 45,000.
- 석면 의심 텍스는 금액을 자동 계산하지 않고 `석면 확인 전 철거 금지`와 전문업체 별도견적을 표시한다.
- 전기·설비 철거: 일반조명 10,000/개, 매입등 5,000/개, 콘센트·스위치 5,000/개, 분전함 150,000/개, 천장형 에어컨 250,000/대, 환풍기·소형후드 50,000/대, 덕트 15,000/m. 스프링클러 철거·캡은 전문업체 별도.
- 화장실 철거: 250,000원/칸 인건비. 변기·칸막이·내부 벽·바닥 타일 철거 포함, 폐기물 별도. 공용 세면대 철거 50,000/개.

### 5.3 설비

- 배관공 350,000원/품, 조공 220,000원/품(선택), 야간·휴일 30%.
- PB 급·온수 15A: 인건비 20,000 + 자재 10,000/m.
- PVC VG1 배수 50A: 25,000 + 10,000/m; 75A: 35,000 + 15,000/m; 100A: 45,000 + 20,000/m. 이음관·보온 포함.
- 코어: 50A 이하 100,000/공(70,000+30,000), 75~100A 150,000/공(100,000+50,000). 구조체 타공 승인 경고 표시.
- 콘크리트 바닥 홈파기 40,000/m(30,000+10,000), 배관 후 몰탈복구 35,000/m(20,000+15,000).
- 설치 인건비: 양변기 80,000, 소변기 100,000, 세면기 100,000, 수전 50,000, 싱크 급배수 연결 100,000/개소, 육가 50,000, 온수기 150,000. 제품비는 브랜드·모델·수량으로 직접 입력.
- 방수: 액방 1회 + 도막 2회, 보호몰탈 미포함. 인건비 120,000 + 자재 80,000/평, 구역당 최소 600,000. 코너·배관 보강 포함.
- 그리스트랩, 배수펌프, 집수정, 수도계량기 분기, 메인밸브, 압력·누수시험, 동파열선은 제품비 직접 입력과 배관공 품 선택 방식.

### 5.4 전기·조명

- 전기공 350,000원/품, 조공 없음. 야간·휴일 30%.
- 상가 기본 전기·조명: 220,000원/평(인건비 90,000, 배선·자재 60,000, 기본 LED 조명 70,000). 일반 배선·스위치·콘센트 배선·기본 LED 포함.
- 디자인 조명, 전용 고용량 회로, 3상, 통신·CCTV·스피커·소방전기는 별도.
- 3상 내부공사: 35kW 이하 1,800,000/식(인건비 700,000, 자재 1,100,000), 36~50kW 2,500,000/식(900,000+1,600,000), 50kW 초과·동력제어는 별도견적. 내부 분전함·차단기·10m 이내 간선·결선 점검 포함.
- 한전 계약전력 증설 불입금, 계량기, 외부 인입은 임대인·건축주 별도 진행 문구를 표시한다.
- 선택 추가: 전용회로 100,000/개소, 인터넷 50,000, CCTV 70,000, 스피커 50,000, 비상·유도등 배선 50,000.

### 5.5 냉난방·환기

- 기계 제품값은 직접 입력하며 설치만 선택할 수 있다.
- 설치: 벽걸이 250,000(150,000+100,000), 스탠드 350,000(200,000+150,000), 천장형 15평 이하 450,000(250,000+200,000), 16평 이상 550,000(300,000+250,000)/대.
- 냉매 동관 추가 30,000/m(8,000+22,000), 드레인 50,000/m(20,000+30,000), 실외기 받침 100,000/대(30,000+70,000), 양중·고소작업 인건비 200,000/식+장비 실비.
- 덕트: 플렉시블 100~150A 25,000/m, 스파이럴 100~150A 50,000/m, 스파이럴 200~250A 75,000/m. 환풍기 설치 인건비 100,000/대+제품비, 디퓨저·그릴 인건비 20,000/개+제품비, 외벽 타공·캡 150,000/개소.
- 주방 후드·대형 사각덕트는 별도견적, 보온덕트 자재비 30% 할증.

### 5.6 금속·유리

- 용접공·유리공 350,000원/품. 조공 별도 없음. 야간·휴일 30%.
- 아연각관/m: 30×30×1.4T 40,000(25,000+15,000), 40×40×1.4T 50,000(30,000+20,000), 50×50×1.4T 65,000(35,000+30,000), 50×50×2.0T 80,000(40,000+40,000). 소모품·방청·로스 15% 포함, 최종도장 별도.
- 강화유리/㎡: 투명 8T 160,000(60,000+100,000), 10T 200,000(70,000+130,000), 12T 240,000(80,000+160,000).
- 강화유리 여닫이문 900,000/세트(250,000+650,000), 슬라이딩문 1,100,000(300,000+800,000). 기본 손잡이·힌지·실리콘 포함, 프레임·잠금·필름 별도.

### 5.7 목공

- 공통 목상: 소송 다루끼 30×30×2400, 12개/단 32,000원. 벽·천장·알판 목상 간격 300mm. 목수 350,000원/품. 로스 15%, 목공본드·타카핀 등 부자재 10%.
- 석고벽: 일반석고 9.5T 900×1800, 5,000원/장, 2PLY. 단면과 양면을 별도 선택하며 양면은 목상을 중복 계산하지 않는다. 생산성 단면 4평/품, 양면 3평/품, 올림.
- MDF 알판: 5T 1220×2440, 9,000원/장, 1PLY. 단면·양면 선택, 목상 공용. 생산성 5평/품.
- 천장: 목상 300mm + 석고 9.5T 2PLY, 생산성 4평/품. 높이 3~4m 인건비 20%, 4m 초과 40% 또는 직접 입력.
- 바닥: 목상 300mm + 구조합판 12T 1220×2440 1PLY, 30,000원/장. 생산성 5평/품. 높이 150mm 초과 인건비 20%.
- 간접등박스 120,000/m(70,000+50,000), 커튼박스 80,000/m(50,000+30,000), 걸레받이·몰딩 목공틀 35,000/m(20,000+15,000). 도장·필름·조명 별도.
- 문틀·출입구 목공 보강 150,000/개소(100,000+50,000). 문·금속프레임 별도.
- TV·선반·상부장용 보강합판 60,000/㎡(35,000+25,000). 가구·선반 제품 및 설치는 제외.

### 5.8 타일

- 일반 바닥 압착: 인건비 90,000 + 부자재 35,000/평. 일반 벽 압착: 110,000 + 40,000/평. 타일 본품 별도.
- 부자재에는 압착시멘트, 일반 줄눈제, 스페이서·레벨링클립, 프라이머, 실리콘, 절단 소모품이 포함된다. 에폭시 줄눈은 제외한다.
- 대형 규격 인건비 할증: 600×600까지 없음, 600×1200 30%, 750×1500 이상 50%. 초대형은 직접 입력.
- 타일 본품 기본 평당 자재비(로스 15% 포함): 600×600 69,000; 600×1200 138,000; 300×600 48,000; 300×300 48,000. 원데이터는 모두 1박스 1.44㎡, 박스가격 각각 26,000, 52,000, 18,000, 18,000. 전체 면적 기준 예상 박스 수도 표시한다.
- 바닥 구배·몰탈미장 80,000/평(45,000+35,000), 벽 평활미장 70,000/평(40,000+30,000). 방수 별도.
- 타일 걸레받이 30,000/m(20,000+10,000), 계단 100,000/단(70,000+30,000), 졸리컷 25,000/m. 타일 본품·금속코너비드 별도.
- 공종 최소 인건비 350,000원.

### 5.9 도장

- 퍼티 2회 + 샌딩 + 수성페인트 2회. 벽 105,000/평(70,000+35,000), 천장 115,000/평(80,000+35,000). 심한 바탕보수·고소작업 별도.
- 에폭시: 코팅 90,000/평(45,000+45,000), 라이닝 1mm 140,000(55,000+85,000), 라이닝 3mm 240,000(75,000+165,000). 연삭·철거·균열보수 별도.
- 철재 방청+에나멜 2회 90,000/㎡(55,000+35,000), 목재 락카·우레탄 110,000/㎡(65,000+45,000), 스테인 80,000/㎡(50,000+30,000).

### 5.10 필름

### 5.11 도배

## 6. 데이터와 상태

- 상가 프로젝트와 견적 인덱스는 주거용 키와 분리한다.
- 견적에는 기본단가 스냅샷, 사용자 수정값, 계산 결과, 적용된 로스·할증·최소금액, 고객용 표시 여부를 저장한다.
- 항목 행은 공종, 세부종류, 단위, 수량, 인건비 단가·금액, 자재비 단가·금액, 경비, 자동계산 산식, 수정 여부, 메모를 가진다.
- 견적 합계는 원가 합계 → 일반관리비 → 이윤 → 부가세 순으로 계산하며 반올림 정책은 기존 주거용과 일치시킨다.
- 저장된 견적을 다시 열 때 동일한 결과가 재현되어야 한다.

## 7. 오류 처리와 보호 장치

- 음수 수량·단가, 숫자가 아닌 입력, 비정상적으로 큰 값은 저장 전에 검증한다.
- 자동 산출에 필요한 면적·규격이 없으면 해당 입력란을 강조하고 산출하지 않는다.
- 사용자 수정값을 자동 재계산으로 덮어쓰지 않으며 `자동값으로 복원`을 제공한다.
- 저장 실패 시 화면 입력을 유지하고 재시도 안내를 표시한다.
- 석면, 구조체 코어, 소방, 한전 증설 등 법규·전문업체 영역에는 경고 및 별도견적 상태를 제공한다.

## 8. 검증 기준

- 모든 공종의 인건비·자재비 분리가 정확해야 한다.
- 평↔㎡ 환산, 15% 로스, 장·박스 올림, 할증, 최소 인건비, 추가 1품 계산을 단위 테스트한다.
- 타일은 평당 본품비와 전체 박스 발주량이 동시에 맞아야 한다.
- 사용자 단가 수정, 자동값 복원, 자동저장·재열기, 고객용 원가 숨김을 통합 테스트한다.
- 기존 주거용 견적 및 프로젝트 데이터가 변경되지 않는 회귀 테스트를 수행한다.
- 데스크톱과 모바일에서 접이식 공종 입력과 우측/하단 요약이 사용 가능해야 한다.
