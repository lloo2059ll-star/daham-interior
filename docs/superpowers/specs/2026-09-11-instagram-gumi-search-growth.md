# 다함 인테리어 인스타그램 구미 검색 노출 프로젝트 설계

## 목표

- 인스타그램 내부 `구미 인테리어` 검색에서 `@daham.co` 계정과 게시물의 자연 노출을 높인다.
- 광고는 사용하지 않는다.
- 노출을 프로필 방문, 공식 홈페이지 클릭, 전화와 DM 상담으로 연결한다.

- 계정: `@daham.co`
- 팔로워: 1,456명
- 프로필 이름: `구미인테리어 대구인테리어 김천인테리어`
- 소개: 구미·대구·김천 시공, 아파트·주택·상가 리모델링 표기
- 연결 링크: `lit.link/dahaminterior`
- 게시물과 릴스가 이미 운영 중이다.

## 전략

1. 프로필 검색 연관성을 `구미 인테리어`에 우선 배정한다.
2. 사용자 이름 `@daham.co`는 유지하고 이름, 소개와 링크를 정비한다.
3. 매주 완공 캐러셀 2개와 시공 과정 또는 공간 설명 릴스 1개를 발행한다.
4. 캡션 첫 부분, 영상 자막, 위치와 해시태그의 주제를 일치시킨다.
5. 조회수보다 비팔로워 도달, 저장, 공유, 프로필 방문과 상담 전환을 우선한다.

## 콘텐츠 원칙

- 사진에서 확인한 사실만 설명한다.
- 한 게시물에는 한 가지 설계 판단을 중심으로 담는다.
- 현장명, 지역, 평형을 명확히 적는다.
- 해시태그는 관련성이 높은 5~8개만 캡션에 사용한다.
- 기존 블로그 글의 문장을 복사하지 않고 인스타그램용으로 짧게 재구성한다.
- 릴스는 10~20초 세로형으로 제작하고 음악은 게시 단계에서 인스타그램 제공 음원을 선택한다.

## 측정

- `구미 인테리어` 검색의 계정·게시물·릴스 노출 여부
- 비팔로워 도달과 검색 유입
- 저장, 공유, 프로필 방문
- 홈페이지 클릭, 전화와 DM 문의
- 4주 단위 콘텐츠 유형별 상담 전환

## 금지 사항

- 팔로워, 좋아요와 댓글을 구매하지 않는다.
- 무관한 인기 해시태그를 사용하지 않는다.
- 같은 캡션과 해시태그를 반복 게시하지 않는다.
- 확인되지 않은 시공 범위나 현장 정보를 작성하지 않는다.
