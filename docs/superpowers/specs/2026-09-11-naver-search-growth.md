# 네이버 홈페이지 상위 노출 설계

## 목표

`daham-interior.com`을 네이버 일반 통합검색의 웹문서 영역에서 강화한다. 브랜드·지역 결합 검색어의 순위를 먼저 안정화하고, 장기적으로 `구미 인테리어` 일반 키워드의 1페이지 진입을 목표로 한다.

## 2026-09-11 기준선

- `다함 인테리어`: 홈페이지 1페이지 미노출
- `다함 인테리어 구미`: 일반 웹문서 4위
- `구미 다함 인테리어`: 일반 웹문서 3위
- `구미 인테리어`: 홈페이지 1페이지 미노출

플레이스, 네이버 블로그, 광고, `site:` 검색 결과는 홈페이지 노출 순위에 포함하지 않는다.

## 원칙

- 메인 페이지가 이미 `구미 인테리어` 대표 페이지이므로 동일 목적의 별도 랜딩 페이지를 만들지 않는다.
- 검색어 반복이나 얇은 지역 페이지 대량 생성 대신 실제 시공 경험과 고유 정보를 늘린다.
- 사진만 있는 갤러리가 아니라 현장별 고유 URL과 검색 가능한 설명을 제공한다.
- 블로그 원문을 홈페이지에 복제하지 않는다.
- 순위 보장은 하지 않으며 네이버 서치어드바이저 데이터와 동일 조건 수동 검색으로 성과를 판단한다.

## 성공 기준

### 30일

- 서치어드바이저의 수집 오류와 SEO 오류 0건
- 공개 포트폴리오 전부 고유 URL, 제목, 설명문, H1, 대표 이미지 설명 보유
- 네이버 플레이스·블로그·당근의 업체명, 주소, 전화번호, 홈페이지 주소 일치
- 브랜드 검색어 3종에서 홈페이지 1페이지 노출

### 60일

- 브랜드·지역 결합 검색어 2종에서 일반 웹문서 1~3위 유지
- 홈페이지 포트폴리오 문서의 네이버 노출 쿼리와 클릭 발생
- `구미 아파트 인테리어`, 구미 지역·아파트명 조합 검색어의 노출 확대

### 90일

- `구미 인테리어` 일반 검색 1페이지 진입을 1차 목표로 평가
- 미진입 시 노출 쿼리, CTR, 외부 언급, 경쟁 결과를 근거로 2차 계획 수립
