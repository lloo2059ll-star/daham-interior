# 추가공사 금액 확인서

## 목적
사용자가 공사 내용과 금액을 직접 입력하거나 손으로 적을 수 있는 깔끔한 빈 양식을 ERP에서 연다.

## 화면과 출력
- ERP 메뉴와 대시보드 문서 카드에서 `additional-work.html`을 연다.
- 첫 화면은 현장명, 고객명, 작성일, 공사 내용과 금액 7행, 부가세 표시, 비고, 확인일이 모두 빈칸이다.
- 내용을 입력하면 미리보기에 반영되고 금액 합계만 계산한다. 금액은 원 단위 정수, 쉼표 입력과 음수 감액을 지원한다. 부가세 포함/별도는 사용자가 선택한 표시이며 세액을 임의로 더하지 않는다.
- 설명문, 약관, 청구·입금 처리, 기존 계약금액 변경을 추가하지 않는다.
- `빈 양식 출력`은 입력 중인 데이터를 지우지 않고 전체 공란을 출력한다. 작성본은 `인쇄 / PDF 저장`으로 출력한다.
- 기본 7행은 A4 세로 1장. 긴 내용과 추가 행은 잘리지 않게 다음 장으로 이어진다. 인쇄에는 버튼·입력 컨트롤·상태 메시지가 나오지 않는다.
- 저장은 로그인 사용자별 이 브라우저의 임시저장만 제공하고 이를 화면에 명시한다. 자동 복원하지 않고 `불러오기`로 복원한다.

## 접근과 데이터
기존 auth.js 및 DAHAM_AUTH.ready를 사용한다. 운영 DB, 정산 extras/costs, 견적, 계약, 기존 문서 저장키를 변경하지 않는다. 입력은 HTML로 해석되지 않도록 모두 이스케이프한다.

## 결정한 접근
기존 공사 안내문처럼 독립된 문서 페이지를 추가한다. 정산의 extras는 시공 원가라 이번 고객 확인서 저장에 재사용하지 않는다. 다함 이름과 절제된 회색 표, 충분한 작성 여백을 사용한다.
