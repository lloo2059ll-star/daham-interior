# 다함 인테리어 네이버 플레이스 자연 노출 프로젝트 설계

## 목표

- 광고를 사용하지 않는다.
- 주력 검색어 `구미 인테리어`의 자연 플레이스 순위를 20위권, 10위권, 최종 5위권 순서로 높인다.
- 보조 검색어 `구미 아파트 인테리어`, `구미 리모델링`은 자연 플레이스 10위권을 목표로 한다.
- 브랜드 검색어에서는 현재의 정상 노출을 유지한다.

## 기준값 (2026-09-11)

광고 표시 결과를 제외하고 일반 고객 검색 화면에서 확인했다.

| 검색어 | 현재 상태 |
| --- | --- |
| 다함 인테리어 | 자연 플레이스 1위 |
| 다함 인테리어 구미 | 단독 플레이스 카드 노출 |
| 구미 다함 인테리어 | 플레이스 정상 노출 |
| 구미 인테리어 | 플레이스 2페이지 이내 미노출 |
| 구미 아파트 인테리어 | 상단 플레이스 결과 미노출 |
| 구미 리모델링 | 상단 플레이스 결과 미노출 |

순위는 사용자 위치, 로그인 상태, 검색 이력과 시점에 따라 달라질 수 있으므로 이후 비교는 같은 환경에서 수행한다.

## 개선 축

1. 업체 정보: 업체명은 실제 상호를 유지하고 업종, 주소, 전화, 영업시간, 홈페이지를 정확하게 연결한다.
2. 검색 연관성: 실제 제공 서비스에 한해 대표키워드 최대 5개와 소개 문구를 정비한다.
3. 콘텐츠 품질: 대표 사진과 현장 사진을 현관, 거실, 주방, 침실, 욕실 등 공간별로 정리한다.
4. 외부 연결: 공식 홈페이지, 네이버 블로그와 플레이스의 상호·주소·전화 정보를 일치시키고 블로그 글에 정확한 플레이스 지도를 연결한다.
5. 실제 이용자 신호: 실제 고객에게만 리뷰 참여 경로를 안내하고 모든 리뷰에 구체적으로 답변한다.
6. 측정: 자연 순위, 전화, 길찾기, 홈페이지 클릭과 상담 전환을 분리해 기록한다.

## 금지 사항

- 광고 순위를 자연 순위로 집계하지 않는다.
- 허위·대행·보상성 리뷰를 만들지 않는다.
- 업체명에 검색어를 임의로 붙이거나 대표키워드를 반복하지 않는다.
- 사진으로 확인되지 않은 시공 내용이나 확인되지 않은 서비스 범위를 등록하지 않는다.
- 위치와 계정 조건이 다른 결과를 직접 비교하지 않는다.

## 운영 주기

- 일일: 같은 날 중복 측정을 피하고 의미 있는 변동만 기록한다.
- 주간: 매주 월요일 검색어별 순위, 전주 대비 변화, 실행 조치와 다음 주 계획을 보고한다.
- 월간: 플레이스 유입 행동과 실제 상담 전환을 검토해 키워드 및 콘텐츠 우선순위를 조정한다.

## 성공 기준

- 1차: `구미 인테리어` 자연 플레이스 20위권 진입
- 2차: `구미 인테리어` 10위권 진입 및 보조 검색어 중 하나 10위권 진입
- 최종: `구미 인테리어` 5위권 진입 후 4주 이상 유지
