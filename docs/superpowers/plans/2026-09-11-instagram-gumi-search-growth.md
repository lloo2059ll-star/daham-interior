# 다함 인테리어 인스타그램 구미 검색 노출 실행 계획

## 1. 기준값 수집

- 동일한 비팔로워 계정과 조건으로 `구미 인테리어`를 검색한다.
- 계정, 게시물과 릴스 탭에서 `@daham.co`의 노출 여부를 기록한다.
- 프로페셔널 대시보드의 최근 30일 인사이트를 저장한다.

## 2. 프로필 정비

- 이름을 `다함 인테리어 | 구미 인테리어` 중심으로 변경한다.
- 소개 첫 문장에 구미 아파트 인테리어와 주거 리모델링을 명시한다.
- 공식 홈페이지를 대표 링크로 배치한다.
- 연락 버튼, 카테고리와 위치를 확인한다.
- 하이라이트를 완공사례, 주방, 욕실, 시공과정, 상담안내로 정리한다.

## 3. 콘텐츠 제작

- 화요일: 완공 캐러셀 6~10장
- 목요일: 공간별 설계 설명 캐러셀
- 토요일: 10~20초 BEFORE-DURING-AFTER 릴스
- 각 콘텐츠는 발행 전 대표 검수를 받는다.

## 4. 검색 최적화

- 캡션 첫 문장에 지역, 아파트명, 평형과 인테리어 유형을 자연스럽게 배치한다.
- 실제 현장 위치 태그를 사용한다.
- 화면 자막과 대체 텍스트에 사진 내용과 현장 정보를 정확히 적는다.
- 게시물별 관련 해시태그 5~8개를 사용한다.

## 5. 주간 운영

- 매주 검색 노출, 비팔로워 도달, 저장, 공유, 프로필 방문과 링크 클릭을 비교한다.
- 성과가 좋은 공간과 표지 구성을 다음 콘텐츠에 반영한다.
- 의미 있는 변화와 사용자 조치 필요 사항만 즉시 보고한다.

## 6. 4주 점검

- 검색 유입과 상담 전환이 높은 콘텐츠 유형을 선정한다.
- 성과가 낮은 표지, 첫 문장과 콘텐츠 순서를 조정한다.
- 12주 동안 같은 주제로 충분한 데이터가 쌓이기 전 무리한 방향 전환을 피한다.

## 현재 다음 작업

- `@daham.co` 로그인 후 현재 인사이트와 검색 기준값을 수집한다.
- 프로필 변경안을 실제 화면에 적용하기 전 최종 문구를 검수한다.
- 기존 현장 중 첫 캐러셀과 릴스에 사용할 사진을 선정한다.
