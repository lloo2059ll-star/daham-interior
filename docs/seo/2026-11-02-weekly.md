## 3. 기술 정상 여부 및 검색 측정 조건

- 점검일: 2026-11-02 한국시간 오전. 실제 원격 Linux 장비에서 네이버 모바일 `https://m.search.naver.com/search.naver?query=...` 6종 비로그인 초기 HTML을 직접 요청하고, 데스크톱 `https://search.naver.com/search.naver?query=...` 6종과 비교.
- 모바일 요청: iPhone Safari 계열 User-Agent, `Accept-Language: ko-KR`. 데스크톱: Windows Chrome 계열 UA. 로그인 쿠키 별도 주입 없음. HTTP 200 응답. 네이버가 이 접속을 어떤 위치로 판단했는지는 불명확.
- 순위 검증 제한: 실브라우저 화면 캡처 없음, 화면에 렌더된 통합검색 실제 카드 순서·전체 검색 결과 페이지 확인 안 함. 따라서 1페이지 진입이나 정확한 순위 추정하지 않음.
- 공개 사이트 직접 접속 점검: `https://daham-interior.com/`, `robots.txt`, `sitemap.xml` 모두 HTTP 200. 메인 소스 상 canonical 존재, `noindex`는 발견되지 않았다. **이 사실만으로 네이버 색인 및 수집 오류가 없다고 단정하지 않는다.**
- 서치어드바이저 및 스마트플레이스 관리자 지표는 미로그인으로 확인하지 못했다.
