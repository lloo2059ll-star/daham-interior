- 임은동: “임은동 코오롱하늘채 35평의 거실과 수납 구성은 홈페이지 시공 사례에 공간별로 정리했습니다.” 링크: https://daham-interior.com/portfolio/imeun-kolon-35.html

블로그 계정 로그인 후 원문을 유지하며 해당 현장 글에만 한 번 추가한다. 상담 링크와 현장 상세 링크의 역할을 구분한다. 게시된 글의 지도는 실제 구미 사업장 정보와 확인한 뒤 연결한다.

## 신규 현장 발행 흐름

1. 실제 현장명·지역·평형·사진을 확정한다. 공개 동의가 확인되지 않은 고객 정보는 넣지 않는다.
2. 홈페이지에 고유 상세 URL과 제목·설명·H1·대표 사진 alt를 준비한다. 기존 상태·설계 판단·시공·결과는 확인한 사실만 요약한다.
3. 홈페이지 메인/목록/관련 현장에 자연스러운 이름으로 연결하고 사이트맵에 포함한다.
4. 홈페이지 상세 URL의 직접 진입·사진·상담 링크를 검증한다.
5. 블로그에는 사진 흐름과 별도 현장 설명을 작성하고 대응 홈페이지 URL과 정확한 플레이스 지도를 연결한다. 홈페이지 원문 복제는 하지 않는다.
6. 홈페이지에서 공개된 대응 블로그 글로 연결한다. 공개 제목을 확인하지 못한 URL은 게시하지 않는다.
7. URL 검사와 실제 검색 결과는 각각 별도 기록한다. 발행했다고 색인/노출됐다고 기록하지 않는다.

월 2개의 실제 현장 문서와 대응 글을 목표로 하되, 아직 일정에 없는 현장이나 사진을 만들어 채우지 않는다. 다음 발행 후보는 봉곡·옥계의 기존 공개 문서와 대응 글 확인이며 새로운 현장 발행 완료로 집계하지 않는다.
