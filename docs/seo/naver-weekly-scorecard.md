# 네이버 자연검색 점검 기록

## 측정 규칙

홈페이지는 일반 통합검색 첫 페이지의 클릭 가능한 daham-interior.com 문서만 집계한다. 광고·플레이스·블로그·site: 결과는 제외한다. 웹문서 순위와 플레이스 순위는 서로 합산하지 않는다. 정확한 순위를 세지 못하면 미측정으로 남기며 일부 목록 미노출을 전체 순위로 환산하지 않는다.

매 점검에 한국 시간, 검색어, 검색 URL, 브라우저, 로그인 상태, 화면에 표시된 위치, 확인 범위를 기록한다. 로그인/위치 조건이 같은지 확인되지 않은 과거 결과와 순위 변동을 단정하지 않는다. 매주 월요일 첫 실행에 주간 보고를 작성한다. 서치어드바이저의 7일·28일 노출수/클릭수/CTR/쿼리/상위 URL/수집 오류는 관리자 보고서에서 확인한 값만 기록한다.
